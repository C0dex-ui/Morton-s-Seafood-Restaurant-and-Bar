# Morton's Seafood Restaurant & Bar

Madisonville, Louisiana seafood restaurant site for [Morton's](https://www.mortonsseafood.com) at 702 Water Street on the Tchefuncte River.

Hot boiled seafood, oysters, po-boys, and the Cypress Room since 1985.

## Stack

TanStack Start, React, Tailwind.

```bash
npm install
npm run dev
```

Runs on `http://localhost:8080`.
